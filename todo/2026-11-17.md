# 2026-11-17 — The Power of Replit

## What We Built

**A new scroll deck at `/the-power-of-replit`: a field guide to Replit as it
stands in November 2026.** Twelve chapters. It opens on Replit's own prompt box,
walks the five moves from a sentence to a live URL, shows what is in the box and
what it plugs into, then turns practical: ten things worth building, each on a
card that copies a complete, paste-ready prompt.

**The ten prompts are the useful part.** Each one names its features, the
connectors and backend pieces to use, a security section written as concrete
rules, and a "prove it" step: an attack the agent has to run against its own
build and show on screen. The orange tag on each card is the security problem
that prompt forces the agent to solve (tenant isolation, an SSRF guard, hashed
API keys and so on).

**Two comparisons, both interactive.**
- *The field*: Replit and its ten closest rivals on one map — who it is built
  for against how much of the platform is included — with a table underneath.
  Hovering a name lights its row.
- *Replit vs Claude*: ten jobs on a line between the two. The dots start in the
  middle and slide to their side as you scroll.

**Five real screenshots** of Replit's public site (home, the Agent page,
integrations, pricing, security), captured 17 November 2026 and shown inside a
plain browser frame so they read as evidence rather than decoration.

## Key Decisions

- **Shipped unlisted.** The deck is reachable by URL but stays out of the
  gallery and the sitemap until the owner asks to list it — the path the RTS AI
  talk took. One line in `registry.ts` (`visibility`) lists it.
- **Numbers carry their source on screen.** "450+ integrations", the five output
  types and the plan prices are read straight off Replit's pages. Revenue
  (Sacra) and valuation are third-party figures and are labelled as estimates or
  "as reported". A sources list and a not-affiliated note close the deck.
- **The two charts say they are opinion.** Positions on the map and the lean
  chart are editorial judgment; both state that next to the chart.
- **Real screenshots instead of generated art.** The quality bar asks for one
  generated image per three chapters. For a deck about a real product, five real
  screens do that job better than metaphors, and there was no OpenAI key on this
  machine to generate with. No entries were added to `gen-images.mjs`.
- **English only.** Openstage has no i18n port yet, so the deck passes a plain
  chapter list to `<ChapterNav>`, as `ai-patterns` does.
- **Prompts live in a data file** (`the-power-of-replit.data.ts`), together with
  the rivals and the comparison rows, so the layout file stays readable.

## Things worth knowing next time

- `Marquee` fades its edges with a mask over the whole strip. A background
  class on the Marquee itself fades out too, and the light page shows through
  as two pale bars. Put the background on a wrapper.
- `Spectrum` draws its axis labels on the lower row at each end. A sixth item,
  or a long axis label, collides with them. Five items and short axis labels fit.
- A lazy `next/image` prints as an empty frame. The deck's five screenshots load
  eagerly.
